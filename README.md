# Projeto_1
Contador de tempo progressivo.

================//================

Desenvolvi um aplicativo Android em Java que exibe o tempo decorrido desde uma data de referência, com atualização contínua e interface minimalista.

Tecnologias e ferramentas: Java, Android SDK, Termux, Git e GitHub.

O que pratiquei: compilação de código Java, geração e assinatura de APKs, versionamento com Git e publicação do projeto no GitHub.
